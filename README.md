# SafeRoute — website

The website for [SafeRoute](https://apps.apple.com/app/id6768244297), an iPhone
app that scores walking routes against official police crime data and guides
you along the safer one.

**[safe-route.app](https://safe-route.app)**

Everything in this repository is published by GitHub Pages as it stands
(`.nojekyll`), this file included. Nothing is private here, and nothing that
should not be public belongs in the tree.

## What the site has

| Path | What it is | How it is made |
|---|---|---|
| `/` | Homepage | hand-written `index.html` |
| `/safety/` | Neighborhood safety index: a 0–100 score, crime map and breakdown for every area of each covered city, plus city, district and night pages | generated by `tools/render-pages.mjs` |
| `/check/` | Map: check any address, with recent 911 calls, street cameras and (England and Wales) schools where they exist | hand-written app shell, `check/index.html` |
| `/tonight/` | Recent police dispatch calls in the US cities that publish them fast enough | hand-written, `tonight/index.html` |
| `/transparency/` | Which cities let the public see their crime data | generated by `tools/render-transparency.mjs` |
| `/404.html` | What GitHub Pages serves for any missing path | hand-written |
| `/schools/` | Redirect to the Map's schools layer | hand-written |

Shared styles live in `assets/sr.css` (tokens, header, footer, buttons, map
chrome — every page links it). `safety/assets/safety.css` adds what only the
`/safety/` and `/transparency/` pages use. The icon set is `favicon.svg`;
`favicon.ico` and `apple-touch-icon.png` are rasterised from it.

## Coverage and data

As of September 2026 the app covers most of the UK (England, Wales and
Northern Ireland, from every police force that publishes street-level crime to
data.police.uk), 26 US cities, Toronto, Vancouver and Mexico City. The
`/safety/` pages cover 26 of those cities: 18 in the US, 6 in the UK, Toronto
and Vancouver. The homepage's own counts are kept current by
`tools/sync-site-facts.mjs`; this paragraph is not.

- **Crime:** [data.police.uk](https://data.police.uk) for UK forces; each US
  city's police or open-data portal; Toronto Police Service and Vancouver
  Police Department open data; Mexico City's FGJ investigation files through
  [Hoyo de Crimen](https://hoyodecrimen.com).
- **Recent calls:** the police dispatch (911/CAD) feeds that San Francisco,
  New Orleans, Detroit, Las Vegas, Seattle, Cleveland and Minneapolis publish
  (September 2026).
- **Street cameras:** TfL, 511NY/NYSDOT, Nevada DOT, City of Toronto and City
  of Vancouver.
- **Schools:** the Department for Education's register (GIAS), which also
  lists Welsh schools, and Ofsted's inspection outcomes for England.
- **Maps:** © Mapbox © OpenStreetMap contributors; the area-page basemaps are
  drawn from OpenStreetMap (ODbL) and, for New York, NYC Open Data.

Each score is calibrated within its own city, so it compares areas inside one
city, not one city against another. Figures are incidents *reported* to
police. The site is informational only, and SafeRoute is not affiliated with
any police force.

## Privacy

No accounts, no ads and no cookies. The website counts page views with
Cloudflare Web Analytics, which is cookieless and stores nothing on your
device. The app's anonymous usage analytics can be switched off with one
setting. Details are in the
[privacy policy](https://minhajk21.github.io/saferoute-privacy/); questions go
to the [support page](https://minhajk21.github.io/saferoute-support/).

## Building

There is no build step for the hand-written pages: edit and push. Both
generators are deterministic, so re-running one on unchanged data gives an
empty diff.

```sh
node tools/render-pages.mjs          # /safety/**, sitemap.xml, robots.txt, safety/search-index.json
node tools/render-transparency.mjs   # /transparency/ from tools/data/transparency-index.json
node tools/sync-site-facts.mjs       # homepage coverage numbers, from search-index.json
node tools/audit-viewports.mjs       # every page type at 14 screen sizes in headless Chrome
node tools/build-icons.mjs           # favicon.ico + apple-touch-icon.png from favicon.svg
```

`render-pages.mjs` reads the committed gazetteers (`tools/gazetteer/`) and
data cache (`tools/data-cache/`); it makes no network calls. Fresh data comes
from `.github/workflows/rebuild-safety-pages.yml`, which runs on the 2nd of
each month. It refreshes the gazetteers, pulls each area's figures from the
SafeRoute backend (`tools/generate-data.mjs`, paced under its rate limit;
needs the `SAFEROUTE_API_KEY` secret), fetches any new basemaps, checks the App
Store facts the homepage quotes, re-renders both generated sections and the
homepage numbers, and commits the result. The transparency dataset is
measured in the backend repository and pushed here on the 1st.

The monthly job commits with `git add -A`, so raw downloads must never be left
in the tree; the fetchers write to `/tmp` and `.gitignore` backs that up.
`tools/audit-viewports.mjs` needs only an installed Chrome and exits non-zero
on any layout failure.
